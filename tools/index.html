// 어떤 서비스인가요?

Bluedove's Developer Playground는 개발하면서 자주 찾게 되는 도구와 생활에 필요한 계산기, 그리고 브라우저 성능을 재 보는 실험 페이지를 모아 둔 사이트입니다.

모든 기능은 백엔드 없이 브라우저 안에서만 동작합니다. JSON, JWT 토큰, 이미지처럼 민감할 수 있는 입력값도 서버로 전송되지 않습니다. 이미지 변환은 Web Worker, 서명 검증과 UUID는 Web Crypto, QR 코드는 Canvas로 처리합니다.

개발자 실험실로 개편하면서 Next.js를 기반으로 클라이언트 모드로만 동작합니다. PC는 좌측 메뉴, 모바일은 햄버거 메뉴로 같은 도구를 쓸 수 있습니다.

항목내용
프레임워크Next.js 16 (App Router) · React 19 · TypeScript 5
특징정적 빌드 'use client'
라이브러리js-yaml, qrcode, Three.js 0.187.0, PixiJS v3 + pixi-spine
브라우저 APIWeb Crypto, Canvas, Web Worker, Intl, WebGL 2.0

01 · /playground/browser/

브라우저 성능 테스트

어항에 SVG 물고기를 계속 늘려 가며 브라우저가 언제까지 버티는지 재는 테스트입니다. 물고기마다 매 프레임 자바스크립트가 위치와 방향을 계산해 transform을 바꾸기 때문에, JS 실행 속도와 스타일 계산, 레이어 합성 성능이 함께 반영됩니다.

  • 진행 시작하기를 누르면 0.1초마다 물고기가 한 마리씩 늘어납니다.
  • 측정 0.5초마다 실제로 그려진 프레임 수로 FPS를 계산하고, 부하 막대와 그래프로 보여 줍니다.
  • 종료 FPS 20 미만이 10초 동안 이어지면 그때의 물고기 수가 최종 점수입니다. 중간에 회복하면 카운트다운은 처음부터 다시 셉니다.
  • 탭 전환 숨겨진 탭은 애니메이션이 멈추므로 측정을 일시정지하고 카운트다운을 초기화합니다.

02 · /playground/features/

브라우저 기능 진단

현재 브라우저가 어떤 웹 기술을 지원하고, 실제로 쓸 수 있는지 8개 카테고리 73개 항목을 검사합니다. API가 있는지만 보지 않고 가능한 항목은 직접 실행합니다. Web Worker는 메시지를 주고받고, WebAssembly는 작은 모듈로 2 + 3을 계산하고, IndexedDB는 임시 데이터베이스에 쓰고 읽은 뒤 지웁니다.

  • 결과 하나의 총점 대신 상태별 개수와 카테고리별 지원 범위 막대로 보여 줍니다.
  • 상세 항목을 펼치면 검사 방법, 결과 이유, 설명, MDN 문서 링크가 나옵니다.
  • 권한 카메라 · 마이크 · 위치 권한은 요청하지 않고 현재 상태만 읽습니다.
  • 저장 전체 결과를 JSON으로 내려받아 버그 리포트에 첨부할 수 있습니다.

결과 상태

03 · /playground/webgl/

브라우저 GPU 벤치마크

Three.js로 만든 WebGL 2.0 장면 4종을 렌더링해 GPU 처리 성능을 10,000점 만점으로 계산합니다. 측정 해상도는 화면 크기와 상관없이 1280×720으로 고정합니다.

  • Quick Test 약 10초. 3D 렌더링만 돌려 평균 FPS · 1% Low FPS · Frame Time을 확인합니다.
  • Full Benchmark 약 1분 30초. 테스트마다 워밍업 → 부하 단계 측정 → 기준 단계 3회 반복 후 중앙값으로 채점합니다.
  • 단계별 측정 테스트 하나를 골라 부하를 올려 가며 FPS 변화를 표로 봅니다.
  • GPU Time EXT_disjoint_timer_query_webgl2를 지원하는 브라우저에서만 측정하고, 없으면 추정하지 않고 N/A로 둡니다.

테스트 구성

테스트측정 대상가중치
3D Rendering3D 오브젝트 렌더링35%
Particle Stress파티클 대량 렌더링25%
Shader TestFragment Shader · 텍스처25%
Geometry StressVertex · Triangle 처리15%

점수 계산 방식

  • 주사율 상한 회피 브라우저는 모니터 주사율보다 빠르게 그리지 않아서, 한 프레임에 같은 장면을 여러 번 그려 Frame Time을 늘린 뒤 측정합니다.
  • 처리량 작업량 × 반복 횟수 ÷ 평균 Frame Time
  • 점수 가중치 × 10,000 × min(1, 처리량 ÷ 기준 처리량)
  • 기기 보호 워밍업에서 5fps 아래로 떨어지면 부하를 낮춥니다. GPU 등급 · 순위는 표시하지 않습니다.
