// 단어 배틀이란?

단어 배틀(Power of Word)은 두 단어를 넣으면 각 단어가 판타지 캐릭터가 되어 1:1로 전투하는 웹 게임입니다. 캐릭터 머리 위에는 입력한 단어 명이 있고, 라운드마다 공격·방어·크리티컬히트를 주고받다가 마지막 Last Collision에서 승부가 납니다.

결과는 운이 아니라 단어의 힘으로 정해집니다. 서버의 배틀 로직과 단어마다 고유한 지문인 SHA-256 해시를 기반으로 체력과 공격력 그리고 라운드 결과가 정해지기 때문에, 같은 단어끼리는 언제 붙어도 결과가 같습니다. 전투에 출전하는 직업과 공격 위치 같은 연출만 랜덤으로 보여집니다.

// 출전 캐릭터

두 단어에는 매 경기 아래 8개 직업 중 하나가 랜덤으로 배정됩니다. 직업은 승패에 영향을 주지 않고 공격 모션과 이펙트만 달라집니다. 모든 캐릭터는 이동·공격·방어·크리티컬히트·승리·패배 모션을 갖고 있습니다.

전사 WARRIOR 근접

상대에게 돌진해 대형 철퇴를 휘두릅니다. 뒤로 젖혀 멈칫했다가 순간적으로 내려치고, 초승달 궤적이 남습니다. 크리티컬 히트시 힘을 모아 풀스윙해 상대를 일직선으로 날려 벽에 처박습니다.

필살기 · 분쇄 일격
마법사 MAGE 원거리

주문을 외워 상대에게 라이트닝 줄기를 뻗습니다. 크리티컬 히트시 경기장 위로 먹구름을 불러 모아 낙뢰를 두 번 내리꽂고, 마지막에 묵직한 거대 낙뢰를 한번 더 꽂아 바닥에 크레이터를 남깁니다.

필살기 · 천벌의 낙뢰
사제 PRIEST 원거리

금빛의 구체 홀리볼트를 발사합니다. 크리티컬 히트시 빛의 구체 4개를 불러내 하나씩 날려 꽂고, 크게 부푼 마지막 구체가 빛을 내며 사방으로 터집니다.

필살기 · 성광 구체
궁수 ARCHER 원거리

거리를 두고 화살을 쏩니다. 크리티컬 히트시 시위를 당긴 채 바람을 모아 회오리 거대 화살을 날리고, 상대를 휘감아 끌고 가며 연타한 뒤 회오리가 폭발합니다.

필살기 · 질풍 관통
도적 ROGUE 근접

상대 앞까지 빠르게 파고들어 X자로 공격합니다. 근접 직업 중 공격 모션이 가장 빠릅니다. 크리티컬은 그림자 순간이동으로 정면·등 뒤·측면을 오가며 3연격을 꽂습니다.

필살기 · 그림자 난도
성기사 PALADIN 근접

방패를 든 채 돌진해 장검을 크게 휘두르고, 타격 지점에 성광이 터집니다. 크리티컬 히트는 하늘에서 거대한 성검이 떨어져 땅에 꽂히며 바닥을 갈라놓습니다.

필살기 · 성검 강림
무도가 MONK 근접

맨손으로 파고들어 장타를 두 번 짧게 끊어 치고, 뛰어올라 한 바퀴 도는 돌려차기로 마무리합니다. 크리티컬 히트시 물러나 기를 모은 뒤 어깨로 들이받는 붕격, 몸을 돌려 파고드는 운신, 쌍장타 쌍호장으로 이어 상대를 일직선으로 날려 보냅니다.

필살기 · 붕운쌍호장
총잡이 GUNSLINGER 원거리

권총을 빠르게 뽑아 2연사합니다. 총구 화염과 함께 탄피가 튀고 예광탄이 날아갑니다. 크리티컬 히트시 룬 마법진을 펼쳐 조준하고, 공간을 가르는 푸른 궤적의 룬 탄환이 상대를 꿰뚫으며 관통 섬광이 터집니다.

// 작동 방식 · SSR

실제 페이지는 SSR(Server-Side Rendering) 모드로 동작합니다. 전투 결과는 서버가 모두 계산해서 페이지 HTML 안에 담아 보내고, 브라우저는 받은 데이터를 그대로 재생합니다.

  1. 두 단어 입력
    2~16자 단어 두 개를 넣고 START를 누르면 서버로 전송됩니다.
  2. 서버에서 전투 계산
    각 단어의 SHA-256 해시로 체력과 공격력을 정하고, 마지막 라운드까지 HP·공격력·크리티컬 결과를 미리 모두 계산합니다.
  3. SSR로 배틀 데이터가 세팅된 페이지
    계산 결과가 전투 데이터가 페이지와 함께 도착하므로 추가 요청 없이 바로 시작합니다.
  4. 브라우저에서 연출 재생
    round 데이터를 파싱하고 캐릭터가 랜덤 선택된 뒤, Canvas 배틀 엔진이 라운드를 차례로 재생합니다.

// 경기 진행과 연출

  1. 등장
    두 캐릭터가 하늘에서 떨어져 착지하고, 3 · 2 · 1 · FIGHT! 카운트다운으로 시작합니다.
  2. 라운드
    탑다운 경기장을 자유롭게 배회하다 점점 서로에게 끌려가 부딪힙니다. 충돌하면 스파크와 넉백이 일어나고, 공격 순서는 매번 랜덤입니다. 맞은 쪽은 하얗게 번쩍이며 밀려나고, 벽에 닿으면 튕겨 나옵니다.
  3. Last Collision
    마지막 라운드나 HP가 0 이하가 되면 화면이 어두워지고 붉게 맥동합니다. 잔상을 남기며 돌진 → 화이트아웃과 충격파 → 슬로모션 결정타로 이어집니다.
  4. K.O. & 결과
    패자는 회전하며 날아가 바닥에 두 번 튕긴 뒤 픽셀 단위로 폭발합니다. 승자는 중앙에서 승리 포즈를 취하고 후광, 떨어지는 왕관, 꽃가루와 함께 결과 카드를 볼 수 있습니다.

승패 판정

  • 한쪽만 HP 0 이하 다른 쪽이 승리
  • 둘 다 HP 0 이하 HP가 더 높은 쪽이 −10보다 크면 승리, 아니면 무승부
  • 둘 다 남은 채 종료 HP가 높은 쪽이 승리

부가 기능

  • 1X / 2X 경기 속도 전환. 다음 경기에도 유지됩니다.
  • LOG 단어별 HP·해시·라운드 로그를 팝업으로 보여 줍니다.
  • REPLAY 같은 직업 조합으로 경기를 다시 봅니다.
